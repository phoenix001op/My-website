# ❄️ Lavish's Website

My personal website and a collection of my coding projects.

## 🚀 Projects

### 🧮 [Easy](./projects/easy/)
A collection of 36 math tools, including calculators and converters. It has a search bar and a notebook-style design with a chalkboard dark mode.

### 🎮 [Russian Roulette](./projects/russian-roulette/)
A browser game of chance.

### 📚 [Padh Lo](./studytimer.html)
A study timer with a calendar, study statistics, XP ranks and optional screen time tracking.

### ✋ [PowerPalm](./projects/power-palm/)
Uses your camera to track hand gestures and show anime-style visual effects.

### 🔥 [Phoenix](https://phoenix-bi9s.onrender.com)
An anime discovery website. You can browse currently airing anime, search by title, view details, and rate and review shows.

### ✏️ [Guess to Win](https://guess-to-win.onrender.com)
A real-time multiplayer drawing and guessing game. Friends join private rooms using a code, then draw, chat and score points for quick guesses. Built with Node.js, Express, Socket.IO and HTML Canvas.

### 📱 [Phone Controller](https://virtual-controller-u4sh.onrender.com)
Turns your phone into a game controller for your laptop, with layouts for GTA Vice City, Minecraft and car games. It pairs using a code, and a small Python program on the laptop turns phone touches into keyboard and mouse input.
